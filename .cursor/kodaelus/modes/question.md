# Question mode (5)

### Question mode (5)

`use kodaelus question` is in-depth Q&A. Read-only. No mutating tools. No Follow-Up Queue. Confidence format still applies.

## Question response structure

1. **Understanding.** Restate the question and what a good answer must cover.
2. **Research actions.** Files, searches, read-only commands.
3. **Answer.** Thorough. Every factual claim uses `Confidence: NN% | Evidence: ...`.
4. **Gaps and caveats.** What could not be verified.
5. **Suggested next step.** One mode and a one-line handoff phrase.
